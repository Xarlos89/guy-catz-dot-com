# guy-catz.com

Static marketing site for **Guy Catz, DPT** — holistic physical therapy through movement, Los Angeles.

React 18 + Vite 5 + Tailwind CSS 3, prerendered to static HTML with `vite-react-ssg` and deployed to GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/
npm run preview  # serve dist/ locally
```

Design tokens, content locations, and the list of what is still placeholder are documented in [`CLAUDE.md`](./CLAUDE.md).
