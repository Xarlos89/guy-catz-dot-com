# guycatz.com

Static marketing site for **Healing Path Rehabilitation** — the practice of Guy H. Catz, PT, DPT. One-on-one
physical therapy in Los Angeles: at the patient's home, at the West Los Angeles office, or by telehealth.

React 18 + Vite 5 + Tailwind CSS 3, prerendered to static HTML with `vite-react-ssg` and deployed to GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/
npm run preview  # serve dist/ locally
```

Design tokens, content locations, the domain and DNS setup, the SEO notes, and the list of what is still
placeholder are documented in [`CLAUDE.md`](./CLAUDE.md).
